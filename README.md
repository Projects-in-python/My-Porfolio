## 📦 Run Locally

Clone the repository:

```bash
git clone https://github.com/Projects-in-Python/Portfolio-Website.io.git
```

Navigate to the project directory:

```bash
cd Portfolio-Website.io
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```

The application will be available at:

```text
http://localhost:3000
```

## 🌐 Deploy to Netlify

This portfolio is deployed using [Netlify](https://www.netlify.com/).

### 1. Install Dependencies

```bash
npm install
```

### 2. Build the Project

Create an optimized production build:

```bash
npm run build
```

The production files will be generated in the `build/` directory.

### 3. Login to Netlify

```bash
npx netlify login
```

This will open a browser window where you can authenticate with your Netlify account.

### 4. Link the Project

Link the local project to an existing Netlify project:

```bash
npx netlify link --name <your-netlify-project-name>
```

Or use the interactive linking process:

```bash
npx netlify link
```

### 5. Check Netlify Status

Verify that the project is correctly linked:

```bash
npx netlify status
```

### 6. Deploy to Production

Deploy the production build:

```bash
npx netlify deploy --prod --dir=build
```

After a successful deployment, Netlify will display the production URL.

### 🚀 Quick Deployment

Once the project is already linked to Netlify, you only need:

```bash
npm install
npm run build
npx netlify deploy --prod --dir=build
```

### 🔄 Deploy Future Updates

After making changes to the portfolio:

```bash
npm run build
npx netlify deploy --prod --dir=build
```
